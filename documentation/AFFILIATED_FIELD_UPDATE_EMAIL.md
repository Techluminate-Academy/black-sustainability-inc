Great news! I've successfully added the **Affiliated Entity** field to the short form on the [Join Map page](https://maps.blacksustainability.org/join-map).

## 🆕 What's New

The form now includes an **"Affiliated Entity (optional)"** field that allows users to specify if they were referred by another organization to use the map. This field is positioned after the Bio field and before the Submit button.

### 📋 Field Details:
- **Label:** "Affiliated Entity (optional)"
- **Description:** "If you were referred by another organization to use this map, list the name of the organization you are affiliated with. This is SEPARATE from the organization you are representing."
- **Placeholder:** "Enter affiliated organization name"
- **Required:** No (optional field)

## 🔧 Technical Implementation

The field has been fully integrated:
- ✅ **Form UI** - Added to the short form interface
- ✅ **Data Processing** - Properly captures and validates input
- ✅ **Airtable Integration** - Maps to the `"AFFILIATED ENTITY"` field in production database
- ✅ **Form Submission** - Successfully tested and working

## 🎯 User Experience

Users can now:
1. Fill out their basic information
2. Optionally specify an affiliated organization if referred
3. Submit the form successfully to the production database

## 🚀 Live Status

The field is now live and functional at: https://maps.blacksustainability.org/join-map

## 📊 Data Flow

When users submit the form:
- The affiliated entity data is captured
- Stored in the production Airtable database under `"AFFILIATED ENTITY"`
- Available for future reference and member management

The form is ready for users and the affiliated entity information will help track organizational referrals and partnerships.

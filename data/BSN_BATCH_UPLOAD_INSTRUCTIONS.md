# BSN Batch Upload Template Instructions

## Overview
This document provides instructions for using the BSN (Black Sustainability Network) batch upload template to register multiple members at once.

## File Location
- **Excel Template with Dropdowns**: `BSN_Batch_Upload_Template_v2.xlsx`
- **CSV Template (no dropdowns)**: `BSN_Batch_Upload_Template_v1 - BSN_Batch_Upload_Template_v1.csv`

## Recommended: Use the Excel Template
The Excel file (`BSN_Batch_Upload_Template_v2.xlsx`) is **strongly recommended** because it includes:
- ✅ Dropdown menus for all required fields
- ✅ Data validation to prevent errors
- ✅ Proper formatting
- ✅ Instructions built-in

## Column Descriptions & Valid Options

### Required Fields (marked with *)

1. **EMAIL ADDRESS*** - Primary email address of the member
2. **FIRST NAME*** - Member's first name
3. **LAST NAME*** - Member's last name/surname
4. **BIO*** - Description of member and/or their organization
5. **IDENTIFICATION*** - Select from dropdown:
   - African/Afrikan
   - African-American/Black
   - Afro-diasporic (Afro-Caribbean, Afro-Cubano, Black/African-American, Afro-Brazilian, etc.)
   - Black/African-American
   - Black/Afro-Diasporic
   - Of African Descent (Afro-Caribbean, Afro-Cuban, Afro-Colombian, etc.)

6. **GENDER*** - Select from dropdown:
   - Female
   - Male
   - Non-Binary
   - Prefer not to say

7. **PRIMARY INDUSTRY HOUSE*** - Select from dropdown:
   - ☀️ Alternative Energy
   - 🌾 Agriculture/Sustainable Food Production / Land Management
   - 🏘 Community Development
   - 🛖 Eco-friendly Building
   - 💰 Alternative Economics
   - 🧑🏾‍🏫 Education & Cultural Preservation
   - Environmental Justice/Advocacy
   - ♻️ Green Lifestyle
   - 🆘 Survival/Preparedness
   - 🗑 Waste
   - 💧Water
   - 🧘🏿‍♀️ Wholistic Health

8. **Address*** - Full address or location (Country)
9. **Location (Nearest City)*** - City name

### Optional Fields

10. **Email 2** - Secondary email address
11. **ORGANIZATION NAME** - Name of member's organization
12. **WEBSITE** - Website URL
13. **PHONE US/CAN ONLY** - Phone number for US/Canada (format: (XXX) XXX-XXXX)
14. **PHONE NON-US/CAN** - International phone number
15. **ADDITIONAL FOCUS AREAS** - Multiple selections allowed (same options as Primary Industry House)
    - For multiple values, separate with commas
    - Example: "☀️ Alternative Energy, 🌾 Agriculture/Sustainable Food Production / Land Management"

16. **NAICS Code** - North American Industry Classification System code(s)
17. **AFFILIATED ENTITY** - Name of referring organization (if applicable)
18. **Country** - Country name
19. **State/Province** - Select from dropdown (US States & Canadian Provinces):
    - US: Alabama, Alaska, Arizona, Arkansas, California, Colorado, Connecticut, Delaware, Florida, Georgia, Hawaii, Idaho, Illinois, Indiana, Iowa, Kansas, Kentucky, Louisiana, Maine, Maryland, Massachusetts, Michigan, Minnesota, Mississippi, Missouri, Montana, Nebraska, Nevada, New Hampshire, New Jersey, New Mexico, New York, North Carolina, North Dakota, Ohio, Oklahoma, Oregon, Pennsylvania, Rhode Island, South Carolina, South Dakota, Tennessee, Texas, Utah, Vermont, Virginia, Washington, West Virginia, Wisconsin, Wyoming, Washington D.C., Puerto Rico, U.S. Virgin Islands, Guam

20. **State** - (Alternative to State/Province, uses same dropdown)
21. **Zip/Postal Code** - ZIP or postal code
22. **Time zone** - Time zone (e.g., EST, PST, CST)
23. **Include me on Global BSN Map** - Yes/No (TRUE/FALSE)
24. **LATITUDE (NEW)** - Latitude coordinate (if known)
25. **LONGITUDE (NEW)** - Longitude coordinate (if known)
26. **MEMBER LEVEL** - Select from dropdown:
    - Member
    - Core Member
    - Impact Member
    - Legacy Member
    - Featured Member
    - Free Member

27. **Paying Member (keep current)** - Yes/No (TRUE/FALSE)
28. **Equity Member (keep current)** - Yes/No (TRUE/FALSE)
29. **Membership Status Notes** - Any notes about membership status
30. **Send Need Payment Email** - Yes/No (TRUE/FALSE)

## How to Use

### Step 1: Open the Excel Template
1. Open `BSN_Batch_Upload_Template_v2.xlsx` in Microsoft Excel, Google Sheets, or LibreOffice Calc
2. The header row (row 1) contains all field names
3. Row 2 contains instructions
4. Start entering data in row 3

### Step 2: Fill in Member Data
1. Enter one member per row
2. Use the dropdown arrows in columns H, I, L, M, S, T, Z, W, AA, AB, and AD
3. For required fields (marked with * above), ensure all are completed
4. For ADDITIONAL FOCUS AREAS (Column M), you can enter multiple values separated by commas

### Step 3: Data Validation
- The Excel file automatically validates:
  - IDENTIFICATION options
  - GENDER options
  - PRIMARY INDUSTRY HOUSE options
  - ADDITIONAL FOCUS AREAS options
  - State/Province options
  - MEMBER LEVEL options
  - Yes/No fields

- If you enter an invalid value, Excel will show an error message

### Step 4: Save and Upload
1. Save the completed file
2. Upload through the BSN admin portal batch upload feature

## Tips for Success

1. **Keep email addresses unique** - Each member should have a unique primary email
2. **Use consistent formatting** - Especially for phone numbers: (XXX) XXX-XXXX for US/Canada
3. **Verify addresses** - Ensure addresses are complete for accurate mapping
4. **Check required fields** - All required fields must be filled before upload
5. **Test with small batches** - Try uploading 5-10 members first to ensure everything works

## Common Errors to Avoid

❌ **Missing required fields** - All fields marked with * must be completed
❌ **Invalid email formats** - Must be valid email addresses
❌ **Wrong dropdown values** - Use only values from the dropdowns
❌ **Inconsistent phone formats** - Use (XXX) XXX-XXXX for US/Canada numbers
❌ **Multiple values without commas** - Separate multiple ADDITIONAL FOCUS AREAS with commas
